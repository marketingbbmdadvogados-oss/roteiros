# Ficha de justificativa v2

Anexo obrigatório de todo roteiro. Sem ficha, o roteiro não está pronto — mesmo que o texto esteja
ótimo.

Ela existe para uma situação concreta: alguém perguntar *"por que assim?"* e a resposta ser um
documento, não uma conversa.

**O que mudou da v1:** as justificativas deixaram de ser `[PROVISÓRIO]`. Cada uma aponta para um
princípio numerado da base (`base-cureau/principios.md`), extraído de 23 vídeos da @lucureau e
auditado em `base-cureau/auditoria-das-fontes.md`.

> **A confiança do princípio é parte da justificativa.** Uma decisão sustentada por 🟢 e uma
> sustentada por 🔴 não são igualmente defensáveis, e a ficha mostra a diferença em vez de
> escondê-la. Copie o marcador junto com o código.
>
> 🟢 confirmado (fontes independentes + dado do Isaac) · 🟡 corroborado · ⬜ não testado aqui
> 🔴 fonte única · ⚠️ ressalva registrada no princípio

**Por que objetivo é escolha única** — `CUR-020` ⬜ + `CUR-030` 🟡
Ela decide o objetivo **antes** de escrever, não depois. E pedir várias ações ao mesmo tempo
**reduz** a ação em vez de somar: paralisia de escolha. Fechar pedindo comentário *e*
compartilhamento "para garantir" não garante — divide.

**Como escolher a métrica-dona** — `CUR-025` 🟢
Cada formato tem métrica própria; julgar pelo número errado reprova conteúdo bom.

| Formato | Métricas que importam |
|---|---|
| Reel | compartilhamento · retenção · comentário |
| Carrossel | salvamento · repost · tempo de tela |
| Story | resposta · saída · retenção |

E cruzando com a calibração real do @isaacbertolini: **carrossel de autoridade não se julga por
curtida** — é o formato de maior alcance e menor interação da conta, por natureza.

## 1. Título / gancho (0–3s)

| Campo | Preencher |
|---|---|
| **Gancho falado** | *(a frase literal)* |
| **Gancho escrito** | *(o texto na tela — obrigatório)* |
| **Gancho visual** | *(o que acontece na imagem nos primeiros segundos)* |
| **Gancho sonoro** | *(som marcante, corte, silêncio)* |
| **Tipo** | stat · acusação · dilema · paradoxo · cena de tensão · promessa temporal · contra-narrativa · erro induzido |
| **Loop aberto** | qual pergunta fica sem resposta na 1ª frase? |
| **Clareza em 3s** | do que fala, e **para quem**? |
| **Alternativas descartadas** | 2 ganchos considerados e por que perderam |
| **Métrica que valida** | retenção 3s · % de não-seguidor alcançado |

### Os quatro ganchos são um só — `CUR-001` ⬜
Não é "escolher um gancho". São quatro canais atuando **ao mesmo tempo** nos primeiros segundos:
falado, escrito, visual e sonoro. Ela chama de **ganchismo**. Um gancho sozinho compete com o
polegar; quatro juntos quebram o padrão.

**Se um dos quatro estiver vazio na ficha, o gancho está incompleto.** É a checagem mais rápida
e a que mais reprova roteiro hoje.

### O gancho escrito é o mais importante deles — `CUR-002` 🟢
**O princípio mais bem sustentado da base inteira**, porque é o único em que ela e o número do
Isaac dizem a mesma coisa.

Ela: texto grande na tela contextualiza o vídeo antes de qualquer palavra ser ouvida.
Os dados de 90 dias do perfil: bastidores institucionais como **Story** foram o **pior alcance da
conta**; o **mesmo tema**, reformatado como **Reel com gancho de legenda**, teve o **melhor alcance
para não-seguidor de toda a conta**.

> **O tema nunca foi o problema. Era o formato sem gancho.**

### Clareza antes de esperteza — `CUR-021` ⬜ (os 3 Cs)
Nos 3 primeiros segundos a pessoa precisa entender **do que você fala e com quem você fala**.
Gancho genial que não diz o assunto perde para gancho simples que diz.

Para o Isaac isso tem endereço: o público é de **pares** — advogados, empresários, profissionais
liberais de 25 a 45 anos. Não é trabalhador buscando defesa. O gancho fala com um colega, não com
um cliente em apuros.

### A entrega vale tanto quanto o texto — `CUR-005` ⬜
Quatro pessoas podem ler o mesmo gancho e só uma viralizar. Se o gancho depende de entonação,
a ficha registra **como falar**, não só o que falar.

### A estrutura de 9 batidas — `CUR-008` ⬜ 🔴

```
Ganchismo → Promessa Aberta → Introdução → Bloco 1 → Ponta Solta 1
          → Bloco 2 → Ponta Solta 2 → Solução → CTA
```

**A introdução tem prazo:** levar a pessoa até os **10 segundos**. Passou dali, a chance de ficar
até o fim sobe muito (`CUR-009` ⬜).

> 🔴 **Leia isto antes de tratar como lei.** Esta estrutura vem de **um único vídeo**, em que ela

> e o passo a passo de 2026 — não estão no acervo. É a peça mais importante do método e a de menor
> lastro. Use, registre na ficha, e trate o resultado como **teste**, não como confirmação.

## 3. Trechos / cortes

Uma linha por bloco. Este é o quadro que responde *"por que esse trecho?"*.

| # | Trecho (primeiras palavras) | Função | Por que fica | O que se perde se cortar | Seg. |
|---|---|---|---|---|---|
| 1 | | ganchismo | | | 0–3 |
| 2 | | promessa aberta | | | |
| 3 | | introdução | | | →10 |
| 4 | | bloco 1 | | | |
| 5 | | **ponta solta 1** | | | |
| 6 | | bloco 2 | | | |
| 7 | | **ponta solta 2** | | | |
| 8 | | solução / virada | | | |
| 9 | | CTA | | | |

### Pontas soltas: no mínimo duas, e não são opcionais — `CUR-010` 🟢

Frases que **abrem curiosidade sem entregar nada**, colocadas exatamente onde a pessoa decidiria
sair. Exemplos dela: *"Mas essa nem é a pior parte…"* · *"E o que quase ninguém percebe é que…"* ·
*"Só que existe um erro ainda maior…"*

**Por que é 🟢:** três leituras independentes chegaram no mesmo lugar.
1. Ela, em Reel (`DbCV7PxgZT4`): mínimo duas, espalhadas pelo roteiro.
2. Ela, em carrossel (`Db9aIvrgAMY`): frase de continuidade no fim de cada slide do miolo.
3. Eu, lendo as 15 referências do próprio Isaac, antes de ter acesso a ela: *"rehook é sempre uma
   frase que não informa nada"* — "aí os cientistas fizeram uma maldadezinha", "calma, valente".

Mesma mecânica, formatos diferentes, fontes independentes. **O que ela acrescenta é o mínimo
numérico: duas.**

### A regra do corte
Todo trecho tem função declarada. Trecho cuja função é "explicar melhor" ou "contextualizar" é o
primeiro candidato a sair — **contexto não segura retenção, tensão segura.** Se um trecho não
compra o próximo, não é trecho: é gordura.

E é o primeiro item que alguém corta achando que roteiro é sobre informação. As pontas soltas
custam 2 segundos e não informam nada. É exatamente por isso que funcionam.

### O CTA é consequência, não enfeite — `CUR-013` 🟡/⬜ ⚠️

| Se o vídeo é… | o CTA pede… |
|---|---|
| polêmico, analítico, de timing | **compartilhamento** |
| passo a passo, útil, tutorial | **salvamento** |

**Esta é a resposta direta para "não temos a lógica do CTA".** O CTA deixa de ser escolha de
última hora e passa a ser decidido no começo, junto com o objetivo.

E bate com os números do Isaac: os Reels aspiracionais de carreira (analíticos, com opinião) são
os que mais geram **compartilhamento**; o conteúdo utilitário tipo guia é o de maior taxa de
**salvamento**. A regra dela prevê o que a conta já mostra.

> ⚠️ **Duas camadas, lastros diferentes** — registre qual você está usando:
>
> | Camada | Fontes | Status |
> |---|---|---|
> | CTA **único**, vindo do objetivo | 2 vídeos independentes | 🟡 sustentado |
> | O **mapa** (polêmico→share, tutorial→save) | 1 frase, 1 vídeo | ⬜ 🔴 hipótese |
>
> E a auditoria achou algo que ninguém deve ignorar: **ela enuncia a regra e não a segue.** Os CTAs
> de todo o acervo dela são captação por palavra-chave (`4GANCHOS`, `LULU`, `PAPEL`, `LOBO`…: seis
> palavras, o mesmo PDF), e em dois vídeos analíticos ela pede comentário quando a própria regra
> manda pedir compartilhamento. Um caso confirma, dois contrariam.
>
> Continua sendo a melhor lógica de CTA disponível. **Promissor e confirmado não são a mesma
> coisa**, e a ficha registra os dois.

### CTA pausada — `CUR-031` ⬜
Em conteúdo longo ou denso, cabe um pedido **no meio** (tipicamente salvamento), além do final.
Hipótese barata e diretamente aplicável ao carrossel de autoridade do Isaac — o formato de maior
alcance e menor interação da conta. Se o problema é que ninguém age, um pedido onde a pessoa ainda
está pode valer mais que um no fim.
⚠️ O do fim continua sendo o do objetivo primário. `CUR-030` não é revogado.

### Proibido neste perfil
- CTA genérico falado ("comenta aqui", "curte esse vídeo") — regra de marca não-negociável.
- Captação por palavra-chave no comentário — cai na zona de recrutamento indireto.
- Esfera Legal citada nominalmente, em qualquer hipótese.

## 5. Diagnóstico pós-publicação — `CUR-015` ⬜ 🔴 + `CUR-016` ⬜

**É esta seção que fecha o método.** Sem ela a ficha é papel; com ela, cada decisão vira uma
previsão que o gráfico confirma ou derruba.

Cerca de **1 hora após publicar**, abra a curva de retenção (Insights do Reel) e leia o formato:

| A curva | O diagnóstico | Volta para |
|---|---|---|
| Cai suave e se mantém alta | O vídeo está certo | — |
| **Despenca nos primeiros segundos** | Ganchismo fraco | Bloco 1 da ficha |
| **Cai continuamente no meio** | Conteúdo pouco útil ou aplicável | Bloco 2 |
| **Degrau brusco num ponto** | Aquele trecho específico é ruim — ache o segundo | Bloco 3 |
| **Cai no final** | CTA mal posicionado ou mal executado | Bloco 4 |
| **Zera logo de cara** | A estrutura inteira está errada | Bloco 2, do começo |

> **Isto é o que faltava.** Hoje "o vídeo foi mal" é frase sem ação. Com a curva, vira
> *"a queda foi no segundo 4, então o problema é o gancho"* — e a ficha diz exatamente qual
> decisão revisar.

**Diagnosticar ≠ julgar.** A curva de um vídeo diagnostica **aquele vídeo**. Só o agregado julga a
estratégia. Sem essa distinção o time abandona um formato bom no terceiro flop — risco concreto no
carrossel de autoridade, que já se sabe ter interação baixa por natureza.

> 🔴 Os seis padrões vêm de **um vídeo de ~50 segundos**, sem segunda fonte. É a ferramenta de
> diagnóstico mais útil da base e a menos corroborada. Use — e anote quando o diagnóstico bater ou
> não com o que vocês conseguiram consertar depois. **Essa anotação é o que vai confirmar ou
> derrubar o princípio.**

## 6. Conformidade

- [ ] Sem promessa de resultado jurídico
- [ ] Sem generalização absoluta ("todo mundo", "sempre", "nunca", "ninguém")
- [ ] Esfera Legal não citada nominalmente

- [ ] **O argumento e a opinião são do Isaac** — `CUR-035`. O método decide gancho, ordem, corte e
      CTA. O miolo não se delega, nem para IA nem para terceiro. É o limite deste repositório.
