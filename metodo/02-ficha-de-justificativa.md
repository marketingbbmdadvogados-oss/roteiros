# Ficha de justificativa (template obrigatório)

Todo roteiro sai acompanhado desta ficha. Sem ficha, o roteiro não está pronto — mesmo que o texto
esteja ótimo.

A ficha existe para uma situação concreta: alguém (cliente, sócio, o próprio Isaac) perguntar
*"por que assim?"* e a resposta ser um documento, não uma conversa.

> **Objetivo primário é escolha única.** Um vídeo que tenta maximizar comentário e salvamento ao
> mesmo tempo costuma escrever um CTA que não provoca nenhum dos dois. Escolher um é o que torna o
> CTA justificável.

## 3. Trechos / cortes

Uma linha por bloco do roteiro. Este é o quadro que hoje não existe e que responde
*"por que esse trecho?"*.

| # | Trecho (primeiras palavras) | Função na retenção | Por que fica | O que se perde se cortar | Seg. |
|---|---|---|---|---|---|
| 1 | | gancho | | | 0–3 |
| 2 | | ponte / rehook | | | |
| 3 | | âncora de autoridade | | | |
| 4 | | rehook | | | |
| 5 | | virada | | | |
| 6 | | CTA | | | |

**Regra do corte:** todo trecho tem que ter uma função declarada na coluna "função". Trecho cuja
função é "explicar melhor" ou "contextualizar" é candidato número um a sair — contexto não segura
retenção, tensão segura. Se um trecho não compra o próximo, ele não é trecho, é gordura.

### As três lógicas de CTA (e quando usar cada uma)

Isto é o que hoje falta: CTA não é enfeite de fim de vídeo, é o pedido do sinal que o algoritmo
mais valoriza **naquele objetivo**.

1. **Compartilhamento direcionado** — *"manda pra pessoa que…"*.
   Usar quando o vídeo descreve um **tipo de pessoa** (um chefe, um sócio, um colega). Funciona
   porque o espectador não compartilha o vídeo: ele compartilha um **recado que não quer dar na
   cara**. Maior alavanca de alcance para não-seguidor.
2. **Comentário de posição** — pergunta que obriga a pessoa a **se colocar de um lado**.
   Usar quando o tema divide opinião legítima. Só funciona se a pergunta puder ser respondida em
   4 palavras; pergunta que exige parágrafo não gera comentário.
3. **Salvamento utilitário** — *"guarda isso pra quando acontecer com você"*.
   Usar em conteúdo de direito/guia. Volume baixo, mas é o formato de maior taxa de salvamento
   da conta.

**Proibido neste perfil:** CTA genérico falado ("comenta aqui", "curte esse vídeo") — regra de marca
não-negociável do @isaacbertolini.

## 5. Riscos e conformidade

- [ ] Toda afirmação factual tem fonte real conferida (estudo, lei, decisão, número) — nada de memória
- [ ] Sem promessa de resultado jurídico
- [ ] Sem generalização absoluta ("todo mundo", "sempre", "nunca", "ninguém")
- [ ] Esfera Legal não citada nominalmente
- [ ] Termos restritos de recrutamento indireto ausentes fora de contexto
